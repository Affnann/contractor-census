# contractor-census

A cleaned, documented archive of the U.S. Department of Defense's quarterly contractor census reports.

**Status:** work in progress. The data has not been added yet.

## Folders

| Folder | What goes in it |
|---|---|
| `data/raw/` | The original report PDFs, unchanged |
| `data/clean/` | The cleaned data built from those PDFs |
| `code/` | Numbered scripts that turn the raw files into the clean data |
| `figures/` | Charts made from the clean data |

Sources, download dates and licenses are listed in [`data/README.md`](data/README.md).
